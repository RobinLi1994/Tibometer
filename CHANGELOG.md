# Changelog

## 1.0.1

- Reduce idle CPU usage and settings layout work.
- Release dashboard and settings views when closed.
- Exclude local build paths from the distributed app.

## 1.0.0

Initial public release.

- Native macOS menu bar monitoring for Codex 5H and 7D limits.
- Five display styles, quota selection, extra credits, and reset alerts.
- Webhooks for JSON, Slack, Discord, Feishu / Lark, and WeCom.
- 16 languages, with system detection and manual selection.
- Read-only Codex access and local settings storage.
