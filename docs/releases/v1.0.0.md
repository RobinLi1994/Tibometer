# Tibometer v1.0.0

A tiny Codex usage monitor

[Website](https://tibometer.app/) · [Source code](https://github.com/nangcr/Tibometer)

## Highlights

- Native macOS menu bar monitoring for Codex 5-hour and weekly limits.
- Five display styles: percentages, bars, bars with percentages, rings, and rings with percentages.
- Reset notifications and webhooks for JSON, Slack, Discord, Feishu / Lark, and WeCom.
- 16 languages, automatic Codex discovery, and manual application selection.
- Read-only Codex access, local settings, and MIT-licensed source code.

## Download

`Tibometer-1.0.0-macOS-arm64.zip` requires Apple silicon and macOS 14 or later. Sign in to Codex with a ChatGPT account before starting Tibometer.

Unzip the archive, move `Tibometer.app` to Applications, and open it.

This build is ad-hoc signed and not notarized. macOS may block opening the app; you can also [build from source](https://github.com/nangcr/Tibometer#install).

To check the download, place `SHA256SUMS` beside the archive and run:

```bash
shasum -a 256 -c SHA256SUMS
```
